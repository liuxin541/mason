BIM技术合作需求文档一、项目简介本项目是基于MASON平台的**火灾疏散仿真系统**。核心功能是将建筑平面图自动转换为仿真网格，在体素网格上运行火灾蔓延与人员疏散耦合模型，实现“建筑平面图 → 火灾仿真 → 疏散分析”的端到端自动化。**核心目标**：打通从建筑图纸到仿真计算的数据链路，实现“建模即仿真”——无需人工翻模即可将建筑信息直接导入火灾疏散仿真引擎。二、输入（仿真系统 → BIM处理模块）仿真系统向BIM处理模块输入以下内容：| 序号 | 输入项 | 类型 | 说明 ||------|--------|------|------|| 1 | **平面图文件** | String（文件路径） | JPG/PNG/PDF/DWG/DXF 格式的二维建筑平面图 || 2 | **层高信息**（可选） | Double | 每层楼高度，默认3.0m || 3 | **楼层数**（可选） | Int | 建筑总楼层数，默认1层 || 4 | **体素分辨率** | Double | 默认0.5m，体素网格的精细度 || 5 | **输出路径** | String | 体素网格和JSON数据的保存目录 | 三、内部处理流程（BIM方负责实现）BIM处理模块内部需完成以下处理流程：```┌─────────────────────────────────────────────────────────────────────────┐│                    平面图预处理流程（BIM方负责）                         │├─────────────────────────────────────────────────────────────────────────┤│                                                                         ││  平面图输入 (JPG/PNG/PDF/DWG)                                           ││       │                                                                 ││       ▼                                                                 ││  步骤1：格式统一与预处理                                                 ││  ├─ PDF/DWG → 光栅化（转为统一分辨率图片）                              ││  ├─ 倾斜校正（检测并纠正图纸倾斜角度）                                  ││  └─ 去噪与二值化（分离建筑元素与背景）                                  ││       │                                                                 ││       ▼                                                                 ││  步骤2：建筑元素识别                                                    ││  ├─ 墙体识别（直线检测/语义分割 → 墙体轮廓）                           ││  ├─ 门窗识别（矩形检测/目标检测 → 门窗位置和尺寸）                     ││  ├─ 房间分割（墙体围合区域 → 房间边界）                                ││  └─ 文字/符号识别（OCR → 房间名称/功能标签）                           ││       │                                                                 ││       ▼                                                                 ││  步骤3：3D语义重建                                                      ││  ├─ 墙体拉伸（2D轮廓 → 3D墙体，高度=层高）                             ││  ├─ 楼板生成（房间区域 → 楼板面）                                      ││  ├─ 门窗放置（位置+尺寸 → 3D门窗构件）                                 ││  └─ 楼层复制（多层建筑 → 复制到各楼层）                                ││       │                                                                 ││       ▼                                                                 ││  步骤4：语义标记                                                        ││  ├─ 识别安全出口（图中标注/门宽度判断）                                 ││  ├─ 识别楼梯位置（特殊符号/区域检测）                                   ││  └─ 房间功能分类（OCR结果映射到功能类型）                               ││       │                                                                 ││       ▼                                                                 ││  输出：体素网格 + 语义信息                                              ││                                                                         │└─────────────────────────────────────────────────────────────────────────┘```四、输出（BIM处理模块 → 仿真系统）| 序号 | 输出项 | 格式 | 说明 ||------|--------|------|------|| 1 | **处理状态** | String | "SUCCESS" 或 "FAILED"，失败时包含错误信息和失败原因定位 || 2 | **体素网格数据** | 二进制文件 `.voxel` | 3D整数网格，体素类型编码：0=空气, 1=墙体, 2=可燃物, 3=门, 4=出口, 5=楼梯 || 3 | **语义信息** | JSON文件 `.json` | 房间功能标签、安全出口位置及ID、楼梯位置、楼层信息 || 4 | **坐标变换参数** | JSON文件 `.json` | 体素坐标 ↔ 世界坐标的映射关系 || 5 | **处理日志** | 文本文件 `.log` | 处理步骤、耗时统计、识别置信度、警告与错误信息 || 6 | **识别可视化** | 图片文件 `.png` | 标注了墙体、门窗、房间分割结果的预览图，便于人工校验 |五、产出成果合作方需交付以下成果：| 序号 | 交付项 | 说明 ||------|--------|------|| 1 | **平面图预处理模块源代码** | 格式统一、倾斜校正、去噪二值化等预处理功能 || 2 | **建筑元素识别模块源代码** | 墙体、门窗、房间识别的完整实现 || 3 | **3D语义重建模块源代码** | 2D→3D拉伸重建的完整实现 || 4 | **体素化输出模块源代码** | 生成 `.voxel` 和 `.json` 文件的完整实现 || 5 | **集成接口代码** | 仿真系统调用的适配层代码（Python/命令行） || 6 | **接口文档** | 包含调用方式、输入输出格式说明、坐标变换方法、错误码定义 || 7 | **测试数据集** | 不少于10张不同类型平面图的测试用例，包括：住宅户型图、办公楼平面图、商场平面图、带标注的验证集 |六、通信协议6.1调用方式BIM处理模块以**命令行工具**形式提供给仿真系统调用：```bash# 输入：平面图 → 输出：体素网格+语义JSONpython run.py --input floorplan.png --output ./output --voxel-size 0.5 --floor-height 3.0 --floors 1```6.2 输出文件结构```output/├── voxel_grid.voxel      # 3D体素网格（二进制）├── semantic_info.json    # 语义信息├── transform.json        # 坐标变换参数├── process.log           # 处理日志└── debug_vis.png         # 识别结果可视化（可选，供校验）```6.3 错误处理| 错误码 | 含义 | 处理方式 ||--------|------|----------|| `E001` | 无法读取输入文件 | 检查文件格式和路径 || `E002` | 平面图中未检测到建筑元素 | 检查图像质量或手动标注辅助 || `E003` | 房间分割失败（墙体不闭合） | 输出警告，使用近似闭合处理 || `E004` | 体素化内存不足 | 建议降低分辨率或分块处理 || `E005` | 识别置信度低于阈值 | 输出警告，在日志中标明低置信度区域 |
